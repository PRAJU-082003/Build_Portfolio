Projects

IoT-Based Hybrid Power Generation & Monitoring

Graduation Project • Wind + Solar

Designed a small-scale hybrid energy setup combining a PV panel and micro-wind turbine, instrumented with sensors for voltage, current, and RPM. A microcontroller handled MPPT-style control heuristics, safety cut-offs, and data acquisition; telemetry was pushed to a cloud dashboard for live monitoring and basic analytics.

  • MCU: STM32/ESP32 class; drivers for ADC, PWM, and interrupts.
  • Interfaces: I²C sensors, hall/optical RPM capture via timers.
  • Comms: MQTT over Wi-Fi with offline buffering in flash.
  • Safety: over-voltage/current thresholds and dump load logic.
  • Dashboard: live graphs for solar vs wind contribution.

AI-Based Face Recognition (Iris/Eye Region Dataset)

Computer Vision • Deep Learning

Built a compact recognition pipeline targeting the peri-ocular region (iris/eye) for identity verification. The system performs grayscale normalization, eye region detection, and feature extraction with a lightweight CNN, followed by cosine-similarity matching.

  • Pre-processing: histogram equalization, eye/iris crop.
  • Model: shallow CNN with depthwise separable layers.
  • Training: Python + PyTorch, early stopping, LR scheduling.
  • Deployment: ONNX export; real-time CPU-only inference.
  • Evaluation: verification thresholds with ROC analysis.
